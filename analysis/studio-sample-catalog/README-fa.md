# روش بررسی فنیِ ۴۰ بازی نمونه

این پوشه دو گذر مستقل را به هم پیوند می‌دهد: آزمون تجربه‌ی بازی با شناسه‌های `game-01` تا `game-40`، و مشاهده‌ی فنیِ صفحه‌های عمومی. فایل `catalog.json` ورودی رسمی و نرمال‌شده‌ی ۴۰ بازی است.

## آنچه اسکریپت ثبت می‌کند

`technical-audit.json` و `technical-summary-fa.md` با بارگذاری عادی هر صفحه در Chromium ساخته می‌شوند. اسکریپت فهرست منابعی را که همان صفحه بارگیری می‌کند، نوع/اندازه‌ی اعلام‌شده، خطاهای صفحه، متن قابل‌مشاهده، canvasها، تصاویر قابل‌مشاهده و یک تصویر از صفحه‌ی آغازین ثبت می‌کند. فایل‌های JavaScriptِ بارگیری‌شده فقط در حافظه برای نشانه‌های متنیِ احتمالیِ کتابخانه‌ها و نامزدهای ثابت‌های فیزیک بررسی می‌شوند؛ باندل کامل ذخیره یا در مخزن منتشر نمی‌شود.

## بازتولید

در GitHub Actions، اجرای شاخه‌ی `research/studio-sample-catalog-v2` از طریق workflow `studio-sample-tech-audit.yml` کل فهرست را با هم‌زمانی ۲ اجرا می‌کند. push اولیه‌ی فایل workflow، اسکریپت یا کاتالوگ نیز آن را اجرا می‌کند. در اجرای محلی، از Node 20 و Playwright 1.49.0 استفاده کنید و Chromium را از طریق نصب رسمی Playwright آماده کنید؛ سپس در ریشه‌ی مخزن اجرا کنید:

```bash
node scripts/studio-sample-tech-audit.mjs
```

متغیرهای اختیاری `CONCURRENCY` (حداکثر ۲)، `PAGE_TIMEOUT_MS` و `SETTLE_MS` زمان‌بندی را تنظیم می‌کنند. در اجرای Actions خروجی‌ها پس از پایان روی همین شاخه ثبت می‌شوند و یک artifact پشتیبان نیز ساخته می‌شود.

## حدود نتیجه‌گیری

- این اسکریپت فقط صفحه‌ی عمومی را باز می‌کند؛ کلیک، ورود، پرداخت، ارسال فرم، تغییر حساب، درخواست به API خصوصی یا تزریق کد ندارد.
- نام یک کتابخانه در کدِ بارگیری‌شده، اثبات نمی‌کند که همان کتابخانه در صحنه‌ی فعال استفاده می‌شود؛ برای همین فقط «نشانه» است.
- regexهای نام/عدد، «نامزد ثابت» هستند؛ ممکن است false positive/negative داشته باشند و باید با تجربه‌ی بازی تطبیق داده شوند.
- مرور صفحه‌ی آغازین ممکن است تمام فایل‌ها را بارگیری نکند. خطا یا نبودن یک نشانه به‌تنهایی اثباتِ نبودن قابلیت نیست.
- اسکرین‌شات فقط وضعیت صفحه‌ی آغازین را مستند می‌کند؛ آزمون‌های مستقلِ گیم‌پلی منبع رفتار، هدف، پیشرفت، پاداش و جریمه‌اند.
- فایل‌های کامل بازی یا دارایی‌های بازتوزیع‌شدنی نگهداری نمی‌شوند؛ فقط فراداده و یافته‌های محدود برای تصمیم طراحی ثبت می‌شوند.
