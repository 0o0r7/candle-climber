# روش بررسی فنی و تصویریِ ۴۰ بازی نمونه

این پوشه ورودی نرمال‌شده‌ی کاتالوگ را در `catalog.json` نگه می‌دارد. اسکریپت هر ۴۰ URL عمومی را با Chromium باز می‌کند، پنج قاب می‌گیرد و فراداده‌ی بارگذاری را به شناسه‌های `game-01` تا `game-40` وصل می‌کند.

## پنج قاب و داده‌های هر بازی

برای هر بازی، اسکریپت قابِ بارگذاری، تلاش امن برای شروع، پس از چند کلید عمومی، پس از نگه‌داشتن هم‌زمان راست و Space، و قاب دیرتر را ثبت می‌کند. همچنین متن DOM، عنوان صفحه، وضعیت HTTP، خطاهای صفحه، نوع/اندازه‌ی منابع بارگیری‌شده، canvasها، تصاویر DOM و چند نشانه‌ی احتمالیِ کتابخانه‌ی گرافیکی/ثابت‌های فیزیک را نگه می‌دارد. JSON و خلاصه‌ی فارسی پیش از آغاز و پس از پایان هر بازی به‌صورت اتمی ذخیره می‌شوند؛ بنابراین اگر اجرای دسته قطع شود، آخرین checkpoint باقی می‌ماند.

## بازتولید

Workflow `studio-sample-tech-audit.yml` فقط روی شاخه‌ی `research/studio-sample-catalog-v2` اجرا می‌شود. push اسکریپت، workflow یا کاتالوگ اجرای آن را آغاز می‌کند؛ اجرای دستی نیز از همان شاخه مجاز است. با Node 20، Playwright 1.49.0 و Chromium اجرا می‌شود؛ هم‌زمانی ۲، زمان ناوبری ۳۰ ثانیه و بودجه‌ی هر صفحه ۶۰ ثانیه است.

در اجرای محلی، Playwright 1.49.0 و Chromium را آماده کنید و از ریشه‌ی مخزن اجرا کنید:

```bash
node scripts/studio-sample-tech-audit.mjs
```

`technical-audit.json` و `technical-summary-fa.md` روی شاخه commit می‌شوند. قاب‌ها در artifact اجرای GitHub Actions با نام `studio-sample-tech-audit` (نگهداری ۳۰ روز) قرار می‌گیرند تا PNGهای حجیم وارد تاریخچه‌ی دائمی Git نشوند.

## حدود نتیجه‌گیری و ایمنی

- صفحه‌ی عمومی فقط از مسیر بارگذاری معمول مرورگر مشاهده می‌شود؛ هیچ ورود، خرید، پرداخت، فرم، درخواست به API خصوصی یا تغییر حساب انجام نمی‌شود.
- کلیک فقط روی canvas یا دکمه‌ای با نام دقیقِ فعل شروع انجام می‌شود؛ کلیدهای عمومی‌اند و لزوماً کنترل درست هر بازی نیستند.
- قابِ تغییرکرده می‌تواند فقط انیمیشن باشد؛ برای همین تغییر تصویر اثبات کنترل یا گیم‌پلی نیست و مرور مستقل هر بازی لازم است.
- نشانه‌ی کتابخانه در متن JS اثبات موتور فعال نیست؛ regexهای اعداد نیز نامزدهایی‌اند که باید با رفتار بازی تطبیق داده شوند.
- فقط فایل‌های کوچک JavaScript با اندازه‌ی مشخص و در سقف زمانی کوتاه در حافظه بررسی می‌شوند؛ باندل کامل یا دارایی‌های بازی ذخیره/منتشر نمی‌شوند.
- صفحه‌ی آغازین ممکن است همه‌ی سیستم‌ها را بارگذاری نکند؛ نبودن نشانه، اثبات نبودن قابلیت نیست.
