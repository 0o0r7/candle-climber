# COMPARISON MATRIX — CANDLE CLIMBER vs CANDLE CURRENT

Scores are comparative studio judgments from source audit and the shipped variant, not user metrics. A score is not a claim about market adoption.

| Dimension | Candle Climber | Candle Current | Read |
|---|---:|---:|---|
| Visual identity | 9/10 | 8/10 | Candle Climber has a more developed renderer and character roster. Current is more distinct as a cockpit, but intentionally smaller. |
| Instant appeal (10-second test) | 7/10 | 9/10 | Current starts with one verb—steer—and a visible three-lane preview. Climber has more front-loaded choices and copy. |
| Core loop depth | 9/10 | 7/10 | Climber wins on physics mastery, mutations, archive, rivals, ghosts, and route nuance. Current wins on clarity but is intentionally a compact experiment. |
| Retention hooks | 9/10 | 6/10 | Climber has daily seeds, archive, leaderboard, death cards, duels, wreckage, and World 2. Current has deterministic rematches, local notes, and best score only. |
| Economy coherence | 7/10 | 8/10 | Climber has the stronger platform-native future, but much of it is roadmap-shaped. Current keeps rank and optional holder cosmetics cleanly separated, with no implied value. |
| Build risk | 5/10 | 9/10 | Climber is a mature multi-route Next app with data feeds and optional persistence. Current is a small static app with bundled data and one state machine. |
| Platform fit | 9/10 | 7/10 | Climber already speaks the ecosystem’s chart/token/game language and has a researched $WICK path. Current is better as a safe comparison/prototype; any token integration remains future and unverified. |

## Honest verdict

### Where Candle Climber wins

- **Competitive depth:** the fixed-timestep platformer has more expressive skill: variable-height jump, coyote time, jump buffering, crumble timing, rush risk, combo, terrain readability, and a deterministic summit/world-two arc.
- **Proof of product maturity:** real feed adapters, HMAC run tokens, anti-cheat validation, archive practice, leaderboard routes, ghosts, rivals, Death Cards, and a documented QA/audit trail make it the stronger “shipped system.”
- **Ecosystem specificity:** its core promise is already native to the platform story: a chart becomes a level, launches can become future levels, and $WICK has a researched future role.
- **Retention and shareability:** the original has more reasons to return and a more developed social artifact.

### Where Candle Climber loses

- **Discoverability:** the live entry surface asks users to parse many systems before playing. The connected ecosystem research records a founder critique of this exact genre: make the game easier to find when entering the site.
- **Variant learning value:** a second version that keeps the same vertical platformer grammar would not reveal whether the product soul is the chart translation or the platformer itself.
- **Economy timing:** the token layer is compelling but partly deferred; future balance gates and weights need careful implementation to avoid diluting the skill-first promise.

### Where Candle Current wins

- **10-second comprehension:** one screen says what to do, labels all three lane outcomes, and exposes the next calm route before play.
- **Deliberate differentiation:** it changes the physical metaphor, interaction, rendering, and progression language instead of reskinning the original.
- **Safe economy boundary:** score is never token-gated; the future holder layer is cosmetic/accessory-only and explicitly marked unverified until owner input exists.
- **Low-risk deployment:** no external APIs, secrets, wallet integration, database, or copied source. It can survive as a static hosted experiment.

### Where Candle Current loses

- **Depth and social surface:** 24-cell rematches, local best, and Signal Notes are not a substitute for the original’s archive, global board, ghosts, duel, and share loop.
- **Data authenticity:** it intentionally ships a synthetic demo tape, while Candle Climber’s central product proof is real market feeds with honest fallbacks.
- **Long-term platform fit:** it is a variant study, not yet a launch-ready $WICK product. Any on-chain balance gate or recognition-weight ledger is `[UNVERIFIED — NEEDS OWNER INPUT]`.

## What should merge back into the original

1. **Game-first entry:** put the playable viewport and one clear CTA above the fold; move secondary system choices below the first interaction.
2. **Provenance badge:** make the source of today’s terrain visible as a first-class state, especially when a feed falls back or a launch-derived tape is used.
3. **Separate rank from recognition:** never let holder utility change ranked skill score; use cosmetic, route, or archive access for optional status.
4. **Cause-forward failure reporting:** show the exact market regime/candle family that ended a run before showing the leaderboard.
5. **Small-mode experiment:** keep a compact lane/current mode as an onboarding or side mode; it can teach chart direction before the full jump loop.
6. **One-tap retry:** preserve the original’s strong retry behavior but reduce the amount of post-run UI before the next run.

## Studio conclusion

Candle Climber is the stronger flagship product. Candle Current is the stronger comprehension experiment and a useful counterfactual: it shows that the product’s distinctive asset is not only “a platformer with candles,” but the act of reading a changing market pattern and taking a consequence-bearing route. The best product direction is a merged system where Candle Climber remains the deep competitive mode and Current’s clarity/provenance/economy boundaries shape the shell around it.
