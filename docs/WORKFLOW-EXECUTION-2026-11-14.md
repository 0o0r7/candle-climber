## ۲. قرارداد ریسپانسیو (یک‌بار تعریف، همه‌جا رعایت)

| کلاس | عرض مرجع | بریک‌پوینت فعلی در `globals.css` |
|---|---|---|
| موبایل کوچک | 360 | `420`، `480` |
| موبایل | 390–522 | `560` |
| تبلت عمودی | 768 | `640`، `768` |
| تبلت افقی | 1024 | `900` (لندینگ)، `1180` (کانتینر) |
| دسکتاپ | 1280 / 1440 | `1180` container |

قواعد سختِ هر سه دستگاه:

1. **هیچ اسکرول افقی** — `document.documentElement.scrollWidth ≤ clientWidth + 2`.
2. **هیچ کنترل زیر ۴۴×۴۴px** (لمس) و هیچ متن زیر ۱۲px.
3. **هیچ کنترلی پوشیده نشود** — overlayها `pointer-events: none` روی پوسته و `auto`
   روی کارت؛ فوتر و `WalletChip` همیشه hit-testable.
4. **safe-area** برای موبایل: `env(safe-area-inset-bottom)` روی HUD پایین.
5. **تبلت، نسخهٔ تنبل موبایل نیست**: گرید دو ستونی (بازی + پنل کنار) به‌جای
   کشیدن موبایل به عرض بزرگ.
